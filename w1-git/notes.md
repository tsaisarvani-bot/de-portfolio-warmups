# Git Notes (main version)
Four terms to know first:

Branch: a different copy of the main where changes can be made without affecting the main.
Commit: changes made are saved as a snapshot with a message explaining about the changes.
Pull request (PR): it is a request to merge the branch to the main after the team reviews it.
Merge: bringing the changes done in the branch to the main.

teams use pull request for many reasons. few of them are: to protect the important code blocks like the main, it helps to check codes in small blocks brfore adding them to the main, it helps to educate the whole team while discussions before merging, helps to store the changes and store history.
